Overview

One simple, fast player for the music on your phone and the radio stations you love, at home and in the car. It plays local files with no ads and no sign-in. It finds stations from India and the world in a few taps. One playback service runs both the phone and Android Auto, so a song or station started on the phone carries on in the car with no break.

Daily listeners

A clean library for their own MP3 and AAC files, playlists, and resume where they stopped.

Commuters and drivers

Safe car controls, voice commands, and radio that reconnects on weak mobile data.

Indian regional radio listeners

Browse by language (Telugu, Tamil, Hindi, Kannada, Malayalam, Marathi, Bengali and more) and by state.

What sets it apart

  • Local files and online radio in one app, with one queue and one set of favourites.
  • An India section that groups the public Radio Browser directory by language and state.
  • Android Auto from the first release.
  • The core app is free, with no account, no ads and no usage tracking. Only crash reports are sent. A paid subscription adds extras later.
  • We publish no station list of our own. Users add stations themselves or pick them from Radio Browser.
  • The core player is open source under MPL-2.0, so anyone can read the code and check what the app does.

Architecture

Kotlin with Jetpack Compose and Material 3, MVVM with clean architecture layers (UI, domain, data). The one rule that shapes everything: a single Media3 MediaLibraryService owns the only player. Every screen and device talks to its session.

Android Auto

The car shows only what the session's browse tree gives it. The root has four tabs. Lists stay short and shallow, because the car limits how many items and levels a driver may see.

Radio streams

Mobile data in a moving car drops often. A station should come back on its own without the driver touching the screen.

Stream types

HTTP and HTTPS, Icecast, Shoutcast, HLS (.m3u8), and playlist files (.pls, .m3u). Now playing titles come from ICY metadata when the station sends it.

Station sources

Radio Browser API for search by country, language and genre. Pick a server through all.api.radio-browser.info, send a clear User-Agent, and skip stations marked broken.

Your own stations

Users add a station with a name and a stream URL, or save one from the directory. We ship no station list of our own. Stations show a letter tile, not a logo.

Features

Every feature has a priority. Pick one to filter the list. "Where" shows if it is on the phone, in the car, or both.

Content

We play public streams, host nothing and publish no station list. No station logo is shown without permission. Recording needs a legal check first.

Roadmap

Library scan and browse, core playback, queue, resume, radio directory with the India section, favourites, custom stream URLs, ICY titles, reconnect, Auto browse tree, voice play and search, notification, Material 3 UI with mini player.

Premium subscription with Play Billing: stream recording, advanced equalizer, cloud sync, themes, pause and rewind live radio, radio alarm, sound profiles, smart playlists, cast, play from your own cloud storage.
